# Покрокове створення проекту

## Крок 1. Створення репозиторію

На GitHub було створено новий репозиторій для зберігання коду сайту.

## Крок 2. Створення HTML-файлу

Було створено файл `index.html`.

Приклад структури сторінки:

```html
<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>Портфоліо</title>
</head>
<body>
    <h1>Моє портфоліо</h1>
</body>
</html>
```

## Крок 3. Підключення Bootstrap

Для покращення зовнішнього вигляду сайту було підключено Bootstrap через CDN.

```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
```

Після цього стало можливим використовувати готові компоненти та стилі Bootstrap.

## Крок 4. Наповнення контентом

На сторінку було додано:

* заголовок;
* інформацію про себе;
* список проєктів;
* кнопку з посиланням на GitHub.

## Крок 5. Завантаження на GitHub

Зміни були додані до репозиторію за допомогою команд:

```bash
git add .
git commit -m "Оновлення портфоліо"
git push origin main
```

## Крок 6. Публікація через GitHub Pages

У налаштуваннях репозиторію було увімкнено GitHub Pages.

Після цього сайт став доступним через браузер.
